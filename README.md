## Если Incy уже установлен

- **Не удаляйте приложение.** Пока оно на телефоне, оно работает. Но переустановить его из российского App Store уже не получится.
- **Сохраните ссылку подписки** (в Incy: профиль → подписка → «Копировать») в Заметки или «Избранное» Telegram. Она понадобится для переезда.
- Обновлений, скорее всего, больше не будет. Со временем могут появиться ошибки на новых версиях iOS, поэтому готовьте замену заранее.

## Как перенести подписку из Incy в Happ

1. В Incy скопируйте ссылку подписки (начинается с `https://`).
2. Установите **Happ** и откройте его.
3. Нажмите **«+» → «Вставить из буфера»**. Список серверов появится сразу.
4. Выберите сервер → подключитесь.
5. Выключите VPN в Incy, чтобы два приложения не спорили за подключение.

Нет ссылки, только отдельные ключи `vless://…`? Перенесите каждый так же через «Вставить из буфера». А если сервис даёт бота, запросите в нём ссылку подписки и кнопку «Открыть в Happ».

## Incy на ПК и Android

Удаление касается **только российского App Store**. На Android и Windows Incy пока работает, но:
- обновления могут перестать выходить;
- запросы «incy скачать на пк» и «incy apk» — излюбленная тема для подделок. Не ставьте APK и EXE с файлообменников.

Надёжнее сразу перейти на Happ или Hiddify. Подписка та же, переезд занимает минуту.

## Incy не работает: частые причины

| Симптом | Причина | Что делать |
|---|---|---|
| Подключается, но сайты не грузятся | ТСПУ «замораживает» соединение | сервер с XHTTP или Hysteria2 |
| Ошибка подписки | подписка истекла или сервис её сменил | обновить подписку или вставить заново |
| Работает на Wi-Fi, не работает на мобильном | мобильный оператор режет протокол | сервер «Mobile» (XHTTP) |
| Ничего не работает на мобильном в центре города | включены **белые списки** | [гайд по белым спискам](https://github.com/Filizaker2/belye-spiski-obhod) |
